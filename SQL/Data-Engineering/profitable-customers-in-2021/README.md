## 📝 Problem Statement

A company maintains a revenue log for customers over different years. You’ve been asked to identify which customers had a positive revenue in the year 2021, to target them for loyalty programs or upsell opportunities.

You are given a Customers table that tracks:

<pre class="ql-syntax" spellcheck="false">╔═════════════╦══════════╗
║ Column Name ║ Type ║
╠═════════════╬══════════╣
║ customer_id ║ int ║
║─────────────┼──────────║
║ year ║ int ║
║─────────────┼──────────║
║ revenue ║ int ║
╚═════════════╩══════════╝
</pre>
- *customer_id* : Unique ID for the customer.
- *year* : Year for which the revenue is recorded.
- *revenue* : Revenue generated by the customer, which may be positive or negative.
- ( *customer_id, year* ) is the primary key.

Write an SQL query to return all customer_ids from the Customers table where positive revenue in the year 2021.

The result should be returned in any order.

### Example 1

Example:

Input:

Customers Table:

<pre class="ql-syntax" spellcheck="false">╔═════════════╦══════════╦══════════╗
║ customer_id ║ year ║ revenue ║
╠═════════════╬══════════╬══════════╣
║ 1 ║ 2018 ║ 50 ║

║ 1 ║ 2021 ║ 30 ║
