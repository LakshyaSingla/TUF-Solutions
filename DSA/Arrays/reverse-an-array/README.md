## 📝 Problem Statement

Given an array **nums** of **n** integers, return reverse of the array.

### Example 1

<p>

**Input:** nums = [1, 2, 3, 4, 5]</p><p>

**Output:** [5, 4, 3, 2, 1]</p>

### Example 2

<p>

**Input:** nums = [1, 3, 3, 3, 5]</p><p>

**Output:** [5, 3, 3, 3, 1]</p>

### Constraints

- 1 <= n <= 100
- 1 <= nums[i] <= 100

---

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
