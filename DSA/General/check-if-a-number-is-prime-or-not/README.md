## 📝 Problem Statement

Given an integer **num** , return **true** if it is **prime** otherwise **false** .

A prime number is a number that is divisible only by 1 and itself.

### Example 1

<p>

**Input:** num = 5</p><p>

**Output:** true</p><p>

**Explanation:** The factors of 5 are 1 and 5 only.</p>So it satisfies the prime number condition.

### Example 2

<p>

**Input:** num = 15</p><p>

**Output:** false</p><p>

**Explanation:** The factors of 15 are 1, 3, 5, 15 only.</p>As the number has factors other than 1 and itself, So it is not a prime number.

### Constraints

- 1 <= num <= 10^4
