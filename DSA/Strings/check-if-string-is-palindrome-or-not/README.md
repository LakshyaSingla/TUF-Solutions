## 📝 Problem Statement

Given a string **s, r** eturn **true** if the string is palindrome, otherwise **false** .

A string is called **palindrome** if it reads the same forward and backward.

### Example 1

<p>

**Input:** s = "hannah"</p><p>

**Output:** true</p><p>

**Explanation:** The string when reversed is --> "hannah", which is same as original string , so we return true.</p>

### Example 2

<p>

**Input:** s = "aabbaA"</p><p>

**Output:** false</p><p>

**Explanation:** The string when reversed is --> "Aabbaa", which is not same as original string, So we return false.</p>

### Constraints

- 1 <= s.length <= 10^3
- s consist of only uppercase and lowercase English characters.

---

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
