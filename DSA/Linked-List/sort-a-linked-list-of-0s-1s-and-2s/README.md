## 📝 Problem Statement

Given the head **** of a singly **** linked list consisting of only **0, 1 or 2** .

Sort **** the given linked list and return the head **** of the modified **** list.

Do it **in-place** by changing **** the links between the nodes without **** creating new nodes.

### Example 1

<p>

**Input:** linkedList = [1, 0, 2, 0 , 1]</p><p>

**Output:** [0, 0, 1, 1, 2]</p><p>

**Explanation:** The values after sorting are [0, 0, 1, 1, 2].</p>

### Example 2

<p>

**Input:** linkedList = [1, 1, 1, 0]</p><p>

**Output:** [0, 1, 1, 1]</p><p>

**Explanation:** The values after sorting are [0, 1, 1, 1].</p>

### Constraints

- 0 <= number of nodes in the Linked List <= 10^5
- 0 <= ListNode.val <= 2

---

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
